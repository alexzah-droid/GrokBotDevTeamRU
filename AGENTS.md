# Работа над GrokBotDevTeamRU

Работайте в этом репозитории. Нужны Python 3.10+ и стандартная библиотека. Задавайте `--workspace` вне релиза и рабочего проекта. SQLite хранит состояние, историю и события. Проверяйте доступные нативные инструменты.

Запускайте `<venv>/bin/python -B -m unittest discover -s tests -v` и `<venv>/bin/python -B scripts/release.py check`. Разделяйте тесты и живой пилот в отчётах. Обновляйте манифест при изменениях. Публикуйте только по прямому запросу.
