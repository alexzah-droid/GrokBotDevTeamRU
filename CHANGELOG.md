# Изменения

## 1.5.0 — 2026-11-18 — prerelease для пилота

Пятая версия проекта. Живая установка не проверена (`live_verified: false`). Подготовлены три роли, шесть file-backed навыков, контроллер задач, независимые проверки, два режима изменения инструкций, история, trial и откат. Фактическое чтение инструкции ботами и нативная доставка должны пройти живой пилот.

Подтверждение по умолчанию проходит в чате. Два отдельных гранта разрешают запуск испытания и закрепление результата в режиме approval. В режиме autonomous достаточно проверок и наблюдений. Терминальный канал остаётся доступным. Установка в автономном режиме требует гранта.

Исправления по ревью: одноразовые подтверждения с TTL и хэшами действия/diff, запрет фиктивного evidence как разрешения, ограничения автора кандидата, настоящее Git/Python smoke-задание с испорченной реализацией, устойчивый watchdog и шаблон автоперезапуска. Reviewer может добавлять проверки, не ослабляя базовый профиль. Внутренние симлинки проекта разрешены, внешние запрещены.

Сборка игнорирует служебные кэши/AppleDouble, отклоняет runtime в дереве релиза, содержит корневую папку и берёт версию из метаданных. PEP 517 backend на стандартной библиотеке собирает полный пакет для pip. Минимум Python — 3.10; CI 3.10–3.13, минимальные права, actions закреплены по SHA.

Проект неофициальный, не связан с xAI. Правообладатель оригинального кода: alexzah-droid.

Стартовое правило останавливает роль при сбое чтения. Карточка показывает, сколько строк diff видно, и сохраняет команду просмотра полного diff. Публичные страницы доступны на английском и русском.
