# Источники и совместимость


Проверено при подготовке версии 1.5.0. Источники описывают продукт, а не гарантируют доступность нативных инструментов в конкретном аккаунте.

- [Create and manage Bots](https://docs.x.ai/grok-bot/bots): существующие боты могут создавать специализированных помощников; постоянное поведение Personal Bots хранится в памяти, редактируемого description у них больше нет. Поэтому наш bootstrap читает текущую инструкцию из контроллера, а не вызывает непроверенный UpdateAgent.
- [Skills and routines](https://docs.x.ai/grok-bot/skills-routines-and-automations): навык задаёт повторяемую процедуру; private skills имеют общую библиотеку и доступность конкретному боту. В этой поставке используются явно читаемые файлы, без заявления об автоматической регистрации в библиотеке.
- [Message and collaborate](https://docs.x.ai/grok-bot/chat-and-collaboration): боты могут передавать задания. Наш native bridge обнаруживает реальные инструменты и сохраняет результаты; не выдумывает публичный HTTP endpoint для управления ботами.
- [Chat Completions](https://docs.x.ai/developers/model-capabilities/legacy/chat-completions): документированный endpoint для дополнительного текстового evaluator runner. Он отделён от управления Personal Bots и не даёт права расходовать API-бюджет без настройки пользователем.

Ни один из источников не подтверждает, что наш конкретный bootstrap уже установлен и проверен в живом аккаунте. Нативные receipts и отдельный пилот должны подтвердить создание, постоянную память и передачу заданий.

GrokBotDevTeam поставляется как самостоятельный контроллер и шесть оригинальных навыков. Для работы достаточно файлов релиза и инструментов платформы.

Имена `CreateAgent(description=…)` и `UpdateAgent` встречались в прежних материалах. Схемы нативных операций берутся из каталога доступных инструментов текущего аккаунта. Навыки реализации и документации используют локальный код и инструменты проекта. Они не требуют pstack, Cursor или отдельного редактора.
