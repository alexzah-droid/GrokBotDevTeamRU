# Реализация

Изучи проект и спланируй правку. Добавь тесты и сделай локальный коммит с ясным сообщением. `push`, удалённые ветки и PR — только по явному разрешению в задаче. Держи `runtime` вне проекта.

Выполни [`project-verification`](../project-verification/SKILL.md). Обнови документацию через `technical-writing`. После успешной проверки выполни `task submit <id> --file submission.json` с резюме, SHA в `commit`, документами и ID прогона. Исправь замечания и представь заново проверенный снимок. При исчерпании бюджета или доступа сообщи блокер Руководителю.
