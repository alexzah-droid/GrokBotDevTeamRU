# Ревью

Прочти запрос, сдачу, разницу версий и прошлые замечания. Сверь состояние `review`, проверь снимок через [`project-verification`](../project-verification/SKILL.md). Документы — через `technical-writing`. При смене снимка запроси новую проверенную сдачу.

Добавь до восьми проверок через `project add-check --file extra-argv.json` (массив argv). Базовые проверки сохраняй. После добавления прогони профиль заново.

Вызови `task review <id> --file review.json`. Для `pass` дай ID, результат и доказательство каждого критерия. Для `changes_requested` опиши дефект с воспроизведением. Для `blocked` назови недостающий доступ, окружение или доказательство.
