# Проверка проекта

Сверь проект и задачу. Если команды проверки нет, предложи Руководителю реальный argv. Выполни `project verify --task <id>` под своей ролью. Проверь неизменность снимка. Ненулевой код, таймаут, обрезанный вывод или недоступное окружение исключают `pass`. Сообщи о дефекте по процедуре своей роли. Смену базовой команды согласуй с Руководителем.

Для критериев вне автоматической проверки собери самостоятельные доказательства. Укажи ID прогона, снимок, результат и непроверенные области. Утверждай визуальное или живое поведение только по соответствующей проверке.
